# 快速开始

# 1.下载框架

在官方网盘下载千寻微信框架并解压

# 2.开启服务

在框架设置中配置HTTP或者WebSocket

# 3.添加微信

在框架上添加一个微信并登录

# 4.接入开发

将 API 集成到您的应用程序中，开始构建功能

//发送文本消息
curl --location --request POST 'http://127.0.0.1:7777/qianxun/httpapi?wxid=你的wxid' \
--header 'Content-Type: application/json' \
--data-raw '{
    "type": "sendText",
    "data": {
        "wxid": "filehelper",
        "msg": "你好世界"
    }
}'
