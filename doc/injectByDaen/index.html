使用Daen微信注入器

# 🥇4.x及以上

# 通过软件界面

# 通过启动参数

通过带有进程参数的方式来启动Daen微信注入器x64_4.x及以上.exe

参数 解释
weiXinExePath 微信exe目录
dllPath hookDll路径
config 配置参数（启动参数）

:::highlight orange 💡 配置参数（启动参数）的各个参数详解、更多参数说明，请阅读【启动参数】章节 :::

下面提供两种启动方式的案例：cmd shell、易语言

# 启动方式案例1：cmd shell

start "" "C:\Users\Microsoft\Desktop\Daen微信注入器x64_4.x及以上.exe" "--injector-config={"dllPath":"D:\\code\\DaenWxHook4.1.12.26.dll","weiXinExePath":"D:\\Program Files\\Tencent\\Weixin\\Weixin.exe","config":{"callBackUrl":"http://127.0.0.1:8041/server/http/callback","port":"8888","cacheData":"","decryptImg":"1","timeOut":"5000","flag":"","ver":"","noHandleMsg":"10","autoLogin":"0","resend":"0","httpMode":"0","groupMemberEvent":"0","revokeMsgEvent":"0","hookSilk":"0"}}"

# 启动方式案例2：易语言

# 通过启动参数

通过带有进程参数的方式来启动Daen微信注入器x32_3.x及以下.exe

参数 解释
wxPath 微信目录
dllPath hookDll路径
param 配置参数（启动参数）
show 是否显示窗口，0=不显示，1=显示

:::highlight orange 💡 配置参数（启动参数）的各个参数详解、更多参数说明，请阅读【启动参数】章节 :::

下面提供两种启动方式的案例：cmd shell、易语言

# 启动方式案例1：cmd shell

start "" "C:\Users\daen\Desktop\Daen微信注入器.exe" "wxPath=D:\Program Files (x86)\Tencent\WeChat\[3.9.10.16]&dllPath=D:\DaenWxHook3.9.10.16.dll&param={"callBackUrl":"http:\/\/127.0.0.1:989\/wechat\/callback","port":"8888"}&show=0"
