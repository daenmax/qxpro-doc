    发起群聊语音通话（startGroupVoiceCall）

    # 接口说明

    • 接口路径：http://127.0.0.1:8888/wechat/httpapi
    • 请求方法：POST
    • 功能描述：发起群聊语音通话

    # 警告信息

    注意

    只负责“让对方响铃 / 停止响铃”，是无法接通的，且本机微信和手机微信都不会进入/显示通话界面

    # 微信版本支持情况

    提示

    ❌ 3.9.9.34

    ❌ 3.9.10.16

    ❌ 3.9.11.18

    ❌ 3.9.12.16

    ❌ 3.9.12.44

    ❌ 3.9.12.54

    ❌ 3.9.12.56

    ❌ 4.1.2.17

    ❌ 4.1.12.26

    ✅ 4.2.0.53

    # Body请求参数

    参数 类型 必填 说明
    type string 是 接口type
    data object 是 请求数据对象
    data.wxid string 是 群wxid
    data.objWxid string 是 群成员wxid，多个用英文逗号隔开

    # Body请求示例

    {
    "type": "startGroupVoiceCall",
    "data": {
        "wxid": "57881507293@chatroom",
        "objWxid": "wxid_p6ldcwhifrfg22,wxid_ey8n1tcekaih22"
    }
}

    # 响应参数

    参数 类型 说明
    code integer 响应码
    msg string 响应消息
    wxid string 微信ID
    port integer 端口
    pid integer 进程ID
    flag string 标志
    timestamp string 时间戳
    version string 微信版本号
    result object 结果对象
    result.sessionId integer 通话ID，挂断的时候用
    result.roomId string 房间ID，挂断的时候用

    # 响应示例

    {
  "code": 200,
  "msg": "操作成功",
  "result": {
    "sessionId": 207561398,
    "roomId": "o9cq807tJdwWjVL4ua7ISQt4RsXQ_im.wechat_207561398_1"
  },

  "port": 8888,
  "pid": 42312,
  "flag": "",

  "version": "4.2.0.53"
