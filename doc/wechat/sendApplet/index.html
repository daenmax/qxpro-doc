    发送小程序（sendApplet）

    # 接口说明

    • 接口路径：http://127.0.0.1:8888/wechat/httpapi
    • 请求方法：POST
    • 功能描述：发送小程序

    # 微信版本支持情况

    提示

    ✅ 3.9.9.34

    ✅ 3.9.10.16

    ✅ 3.9.11.18

    ✅ 3.9.12.16

    ✅ 3.9.12.44

    ✅ 3.9.12.54

    ✅ 3.9.12.56

    ✅ 4.1.2.17

    ✅ 4.1.12.26

    # Body请求参数

    参数 类型 必填 说明
    type string 是 接口type
    data object 是 请求数据对象
    data.wxid string 是 对方wxid，支持好友、群聊、公众号等
    data.title string 是 标题
    data.content string 是 内容
    data.jumpPath string 是 点击跳转地址，例如饿了么首页为：pages/index/index.html
    data.gh string 是 小程序gh，例如饿了么为：gh_6506303a12bb
    data.path string 否 本地路径或者网络直链

    # Body请求示例

    {
    "type": "sendApplet",
    "data": {
        "wxid": "34457730396@chatroom",
        "title": "哈咯",
        "content": "点我进入饿了么",
        "jumpPath": "pages/index/index.html",
        "gh": "gh_6506303a12bb",
        "path": "C:\\Users\\13301\\Desktop\\1.png"
    }
}

    # 响应参数

    参数 类型 说明
    code integer 响应码
    msg string 响应消息
    wxid string 微信ID
    port integer 端口
    pid integer 进程ID
    flag string 标志
    timestamp string 时间戳
    result object 结果对象
    result.sendId string 发送ID

    # 响应示例

    {
    "code": 200,
    "msg": "操作成功",
    "result": {
        "sendId": "cb3594ac3e35abd17914695850a6eb17"
    },
    "wxid": "wxid_nq6r0w9v12612",
    "port": 7628,
    "pid": 27544,
    "flag": "7643",
    "timestamp": "1741015593840"
}
