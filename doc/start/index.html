    快速上手

    # 1. 下载并启动框架

    🖇️最新版本下载 (opens new window)

    前往网盘下载千寻微信框架Pro x.x.x.x.zip，下载好之后解压，双击千寻微信框架Pro.exe运行（如果杀毒软件拦截或者报毒，是正常现象，添加信任即可）

    # 2. 根据需要下载并安装指定版本微信

    💡

    推荐使用3.9.12.56版本（你不需要担心低版本无法登录问题，直接正常使用即可，软件内部会自动处理）

    百度网盘 (opens new window)

    123云盘 (opens new window)

    前往官方群群文件下载

    # 3. 设置框架

    💡

    如果不会设置，请将鼠标箭头移动到蓝色问号上查看提示

    1. 点击框架设置，再点微信设置
    2. 在HOOK设置分组中，选择你使用的PC微信版本
    3. 在目录设置分组中，设置好微信安装目录和数据缓存目录
    4. 点击保存修改按钮

    # 4. 添加微信

    点击微信管理，点击鼠标右键，在弹出的菜单中选择添加微信-随机端口或者指定端口，然后登录微信即可

    💡

    （登录微信后迟迟不显示？360、火绒、安全中心等杀毒软件导致的，退掉或者添加信任，详细请看【常见问题】章节）

    # 5. 购买授权 或者 申请试用

    购买授权 请点击查看 购买授权

    申请试用 请点击查看 自助管理

    # 6. 使用或者开发插件、第三方系统对接

    使用HTTP API或者WebSocket接入开发，详细请看【开始开发】章节

    或者

    使用DLL插件接入，易语言SDK开发插件或者使用别人分享的插件，在插件管理右键添加。详细请看【开始开发】章节
