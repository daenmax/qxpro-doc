# 🔖客服QQ是多少？

-

您有任何疑问都可以联系客服QQ 1330166564、9410245

# 💡如何查看微信的wxid？

-

使用千寻微信框架Pro登录微信可以看到。鼠标右键，复制wxid可以进行复制

如果要扫赞赏码的话，如下填写即可（由于ios微信留言限制了长度，所以直接粘贴即可，微信会自动截取前16位，这个不影响）

# 💡授权的是什么？

-

授权的是微信账号，不绑定电脑、不限制使用设备

# 💡如何查看授权到期时间？

-

  1. 在框架的-微信管理页面即可看到授权到期时间
  2. 使用接口查询授权信息（getAuthInfo）进行查询
  3. QQ机器人自助查询，请点击查看 自助管理

# 🔥如何更换授权的微信号？

如果授权的微信账号被封、不再使用、授权写错了等，我们支持免费将剩余的授权时间转移到新微信账号上

你有两种更换授权的方式，你任选其一即可

🥇第一种：如果wxid已经绑定了QQ

那么可以使用QQ机器人自助更换授权，请点击查看 自助管理

🥈第二种：如果wxid未绑定QQ

那么请联系任意一位客服QQ9410245、1330166564进行人工更换，提供以下3项内容，按照以下格式，发给任意一位客服即可 （切勿同时发给两位客服）

旧wxid：wxid_xxxxxxxx

新wxid：wxid_xxxxxxxx

旧wxid的付款截图 或者 其他能证明旧wxid是属于你的材料(例如手机微信为的约面截图、框架log日志文件夹里的、微信数据目录的文件夹等)

# 🔥如何查看自己的QQ身份ID

请点击查看 自助管理

# 🔥如何将wxid绑定到QQ身份ID

请点击查看 自助管理

# 当前微信版本过低，请升级至最新版本

框架版本大于等于2.0.7.6,无需任何其他工具

不能直接双击微信图标登录，你需要如下两种方式其中一种

①第一种：在框架上启动微信，扫码登录即可（千寻微信框架Pro.exe-微信管理-鼠标右键-添加账号，还不懂请看：官网文档-快速上手）（微信启动后，正常二维码会自动刷新一次，如果没有刷新，那就关闭微信，重新添加，直到有自动刷新再扫码）

②第二种：通过启动注入、Daen注入器注入来启动微信，扫码登录即可（具体请看官网文档）

# 如何更新框架？

更新不会导致你框架的设置、插件数据丢失，请放心更新

  1. 首先关闭正在运行的千寻微信框架Pro和微信
  2. 然后你只需要下载最新版本的zip压缩包，并解压
  3. 将里面的千寻微信框架Pro.exe和bin文件夹复制，然后粘贴到你现有的框架文件夹中，全部替换即可
  4. 重新运行千寻微信框架Pro和微信，就完成了

# 如何购买卡密？

在 购买授权 页面扫码付款，备注“提卡”，不要备注wxid，因为备注了wxid会自动秒到账

# 如何使用卡密激活、充值、续费wxid授权

需要在千寻微信框架Pro.exe上使用，可在首页点击续费授权或者微信管理鼠标右键账号打开菜单选择续费授权

点击此处查看图片教程

# 框架检测更新失败、登录微信提示"网络异常，请联系官方技术人员"

  1. 框架设置-全局HTTP请求模式，切换到另一个选项，保存，试试
  2. 检查是否存在全局代理，如果存在，请关闭代理

# 如何禁止微信自动更新？

下载网盘中的千寻禁止微信自动更新.bat，双击运行即可

或者

手动修改host文件C:\Windows\System32\drivers\etc\hosts，添加以下内容

127.0.0.1 dldir1.qq.com
127.0.0.1 dldir1v6.qq.com

# 执行云函数接口 超时

首先退出已经登录的所有微信

然后打开你的计算机，找到 C:\Users\你的用户名\AppData\Roaming\Tencent\WeChat\XPlugin

把这个文件夹里的东西全部删除

然后登录微信，等待几分钟后再试即可

# 无法接收到回调消息？

如果你的回调程序在本地电脑，而千寻微信框架或者微信客户端在服务器上，那你得保证你本地电脑有公网IP或者内网穿透，这是网络编程基础常识！

# 无法从谷歌浏览器、Edge浏览器上下载，提示“检测到病毒”

使用网盘中的禁用安全中心-Windows11优化工具.zip工具关闭安全中心

或者

手动关闭系统安全中心的实时保护，打开Windows安全中心，找到病毒和威胁防护，关闭实时保护即可

# 框架上添加了微信，日志显示已启动，但是微信管理不显示

  1. 如果安装了火绒安全软件、360等杀毒软件，请退掉或者添加信任即可
  2. 如果没有安装杀毒软件，那么就是安全中心的问题，按照上图关闭 实时保护即可
  3. 直接使用网盘中的禁用安全中心-Windows11优化工具.zip工具

# 框架上添加了微信，日志显示已启动，微信管理也显示，但是微信登录后无反应

4.x.x.x版本的微信暂不支持非中国大陆注册的微信，看你微信的登录页面，如果是英文则不支持

# 如何查看微信账号到期时间？

在框架的-微信管理页面，右键账号，查看详情即可查看 或者 使用接口查询授权信息（getAuthInfo）进行查询

# 如何使用autMan进行对接？

请参考 https://bbs.autman.cn/d/231-dui-jie-qian-xun-pro (opens new window)

# win7用不了，提示“请联系框架官方技术人员”

TLS版本问题，下载我们网盘里的Win7用不了运行并重启MicrosoftEasyFix51044.zip运行并重启电脑即可

# 发文本消息换行是两行？多了一行？

如果你用的易语言SDK，那么你不应该使用#换行符，而是应该使用字符 (13)，或者使用模块里封装的Text.换行() 对于其他语言，你应该使用\r表示换行，即ASCII码值为13，符号显示为CR

# 发送文本消息 和 发送文本消息2 有什么区别？

发送文本消息最长发送包含2048个字符的消息，如果超出，框架将自动切分成多条消息进行发送

发送文本消息2理论上没有最长消息限制，可以发送一次性发送很长的消息

# 发送文件提示文件不存在

如果D:\\daen\\restart.sh不行，就用D:/daen/restart.sh这种斜杠试试

# 发送xml红色感叹号，发不出去

XML里<fromusername>wxid_nq6r0w9v12612</fromusername>必须为自己的wxid，切记

还是那句话，磨刀不误砍柴工

# emoji收发乱码????

请认真看进阶教程-文本代码章节

还是那句话，磨刀不误砍柴工

# 如何判断发出去的消息有没有发送成功？

自2.0.3.0版本之后，对于发送类的接口，返回报文增加了sendId字段，收到消息回调事件中也增加了此字段，你可以根据此字段来判断消息是否发送成功，如果收到了你发送消息得到sendId的回调，说明发送成功，否则就是发送失败了

# 收到语音消息，如何获得silk文件？

首先，保证框架使用的是 2.0.5.0 版本及以上，微信使用的是 3.9.12.54 版本及以上

然后在【框架设置-微信设置-HOOK设置】中勾选【HOOK语音文件】，点击保存修改，然后重新登录微信

之后你收到语音消息后，就会在【数据缓存目录\silk】中生成silk文件
